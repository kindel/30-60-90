# 30-60-90

A coming-soon interactive app that writes a 30/60/90 plan document so the first quarter is inspectable.

## The Model

Hiring ends when they are kicking ass, not when the offer is signed. The 30/60/90 is the inspectable plan for that.

1. **Role**: The 12-month excellence hypothesis. What great looks like in this seat.
2. **Day 30**: Learn the customer, the system, and the people. Named outcomes, not orientation checkboxes.
3. **Day 60**: Own a real slice. Ship something that can fail in public.
4. **Day 90**: Operating at the bar. The inspect: would we hire them again?

A plan without dates is a wish. A 30/60/90 without inspectable outcomes is onboarding theater.

## Why it works

The JD is a hypothesis. The first 90 days is the experiment. Write the plan before day one so the hiring manager and the new hire share one document.
